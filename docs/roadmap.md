# Дорожная карта

## Этап 0 — разведка (закрыт, кроме схемы ответа)
- [x] Личный кабинет работает поверх JSON API `/lk/n-api/...`, парсинг HTML не нужен
- [x] Известны эндпоинты: `schedule`, `profile`, `auth/*`, `schedule/lms-link`
- [x] Эндпоинт и полезная нагрузка логина — `POST auth/login`, multipart
- [x] Глубина расписания: ограничения нет, дни перечисляются в `dates[]`
- [x] Кабинет закрыт WAF: без браузерных заголовков — `403 Forbidden`
- [x] Продление доступа без пароля — `auth/refresh`
- [x] Схема ответа `/lk/n-api/schedule` — снята с живого ответа; признака отмены в ней нет
- [x] Откуда брать группы для `filter[]` — `manual/student-groups`; анкета `profile` не нужна
- [x] Обязательный заголовок `version: 1.0` — без него любой запрос получает 400
- [ ] Срок жизни refresh-токена — как часто просить повторный вход

Подробности: [api-notes.md](api-notes.md)
